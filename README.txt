MORAL GAMES — исходники

СТЕК:
- HTML5 — структура страниц и игровые элементы.
- CSS3 — оформление и адаптивная вёрстка.
- JavaScript (Vanilla JS, без фреймворков) — игровая логика.
- Canvas 2D — отрисовка Tetris и Flappy Bird.
- DOM/CSS Grid — игровое поле 2048.
- localStorage — сохранение рекордов в браузере.

СЕРВЕРНАЯ ЧАСТЬ НЕ НУЖНА:
Каждая игра — самостоятельный HTML-файл. Откройте файл в браузере или разместите его на статическом хостинге.
Внешние библиотеки и сборщик (Vite/Webpack) не используются.
